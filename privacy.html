Privacy policy

Content Publisher · last updated 25 October 2026

Content Publisher is a personal tool that runs on its owner's own computer and posts videos to the owner's own YouTube channels and Instagram professional accounts. There is no server operated for other users; everything below happens on that one computer.

What it accesses

  • YouTube (Google sign-in): uploads videos to the signed-in channel, reads the channel's name, and reads view counts and other YouTube Analytics for the videos it posted.
  • Instagram (Instagram sign-in): reads the account's username, publishes Reels to it, and reads insights such as views for the Reels it posted.

Where it is kept

Sign-in tokens, the posting queue and the view counts are stored only on the owner's computer. They are not sent to any server run by this app, not sold, not shared with anyone, and not used for advertising. Videos are sent only to the platform they are being posted to.

Google user data

Content Publisher's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses the YouTube API Services; see the Google Privacy Policy.

Removing access

Disconnect an account inside the app, which deletes its token from the computer, or revoke access at any time at myaccount.google.com/permissions (Google) or in Instagram under Settings → Website permissions → Apps and websites.
